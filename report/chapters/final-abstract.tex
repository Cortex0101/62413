RatMan is a Windows maze-chase game in which a player collects cheese while avoiding cats. It includes a board builder, configurable movement controls, and a local leaderboard for each maze layout. A WPF interface uses Model--View--ViewModel to present a separate C\# game engine. Fixed simulation steps make movement and collision behavior reproducible, and shared maze topology governs the editor, player movement, and cat navigation. Versioned files store boards, settings, and scores. A Windows test run passed all 208 automated tests, covering engine rules, persistence, and selected interface behavior. The report also describes how developers supervise AI-assisted work throughout the project.
